# Axon (care_path)

تطبيق Flutter + Django REST يربط المريض والطبيب والمهندس حول جهاز علاجي.

- الباكند: Django 6.1 + PostgreSQL (المجلدات: accounts, devices, cases, treatments, feedback, chat, notifications, app_updates)
- الواجهة: Flutter (lib/)
- النشر: راجع SERVER_SETUP.md
- الإعدادات: انسخ .env.example إلى .env (للتطوير ضع DEBUG=True)
